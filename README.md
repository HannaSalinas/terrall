# Terrall 🗺️

Plataforma interactiva con mapa 3D de Colombia para explorar transporte, turismo, educación y economía desde un solo lugar.

## Stack
- **Frontend:** React + Vite + Three.js
- **Backend:** Node.js + NestJS
- **Bases de datos:** PostgreSQL + MongoDB
- **Despliegue:** AWS

## Módulos
- [ ] Mapa 3D base de Colombia
- [ ] Autenticación de usuarios
- [ ] Transporte
- [ ] Turismo
- [ ] Educación
- [ ] Economía informal
